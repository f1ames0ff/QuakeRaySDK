## 1. Golden Rules: Strict Responsibility Boundaries & Single Shared Scene Pipeline

Never mix engine-specific game code with SDK/editor core code across PRs or repositories, **and NEVER duplicate static scene loading, material baking, DTAL construction, light clustering, or sky/overlay pipelines between `quakerayeditor` and the game runtime renderer**.

| Layer | Repository | What Belongs Here | What **NEVER** Belongs Here |
|---|---|---|---|
| **SDK Core & Shared Scene Runtime** | `QuakeRaySDK` (`Include/qray/`, `Source/`, `editor/`, `Tests/`) | Public C ABI (`qray.h`), Vulkan/NVRHI ray-tracing backend, shaders (including Relief POM, path-space specular firefly limiting, sub-pixel LEADR bump regularization), C++ contracts (`host_contract.h`, `gpu_context.h`); bundled runtime assets (`Assets/textures/`); generic `quakerayeditor` HiDPI UI (`EditorGui*`), gizmos, and isolated `quakeray_ai_worker` (`ggml-vulkan`); plus the **single shared scene runtime layer** (`EditorSceneRuntime.{h,cpp}`, `EditorDtalPipeline.{h,cpp}`, `EditorOverlayPipeline.{h,cpp}`, `EditorSession`, `EditorMaterial`, `EditorSettings`, `EditorSpatial`, `Scene`, `Assets` + `EditorAssetVfsCallbacks`) and engine-agnostic hooks (`EditorFormatAdapter`, `QR_EDITOR_ADAPTER_SOURCES`, `QR_EDITOR_ADAPTER_INCLUDE_DIRS`). | Game-specific BSP/portal/shader/model loaders (`IBSP` v38/v46/v47, `BSP30`, `.proc`, `.shader`, `.wal`, `.wad`, `.md2`/`.md3`/`.mdl`/`.mdc`/`.mds`/`.md5mesh`, `lights.rad`), hardcoded game asset lists (e.g. `flame.mdl flame2.mdl`), or host cvar/filesystem code. |
| **Host Engine Format Adapter & Runtime Dynamics** | Host engine repo (id Tech 2 / GoldSrc / id Tech 3 / id Tech 4 / custom host) | Submodule pinning (`code/quakeraysdk`); **one** game format adapter compiled into **both** `quakerayeditor` (`QR_EDITOR_ADAPTER_SOURCES`) and the runtime renderer; host VFS glue (`EditorAssetVfsCallbacks`); and **only per-frame gameplay dynamics** layered on top of `EditorSceneRuntime` (dynamic models via `ResolveDynamicMaterial` + `BuildEditorDynamicMeshAreaLights`, moving inline brush submodels `*1..*N`, sprites/beams, decals/smoke, dynamic `dlights` via `EditorClusterLightUploadExtras`, 2D HUD) plus headless `QR_STATIC` parity tests (`qray_authored_tests`). | A parallel host-side BSP/YAML/material/DTAL/sky/light loader or duplicated static scene builder alongside `EditorSceneRuntime`. Core SDK or generic `quakerayeditor` UX fixes committed into the host repo. |

### Zero-Duplication Mandate, Separate PRs, & Submodule Merge Order
- **One static scene pipeline for both targets:** Every feature affecting static BSP loading, material overrides/bakes (including Relief POM `texture_height`/`parallax_scale`, non-destructive PBR master toggles `emissive_enabled`/`gloss_enabled`/`sss_enabled`, and embedded masks), DTAL area-light clipping/building, light cluster tables, world overlays, sky/sun, `qray.materials.yaml` / `qray.lights.yaml` loading, or meter conversion (`EditorDrawFrame`) **must** go into the shared layer (`EditorSceneRuntime` / `EditorDtalPipeline` / `EditorOverlayPipeline` in `QuakeRaySDK/editor/`) so `quakerayeditor` and the runtime renderer behave 1-to-1 by construction.
- Generic `Include/`, `Source/`, or shared `editor/` changes go into **QuakeRaySDK** PRs; host VFS callbacks, runtime dynamic entity uploads, and game-specific `EditorFormatAdapter` implementations live in the **host repository**.
- **Merge order:** Always merge `QuakeRaySDK` PRs **before** updating host submodule SHAs (squash-merge creates a new commit hash and invalidates pre-merge refs).

## 2. Quick Integration Checklist (New Engine or Editor Adapter)

1. **Read the contracts before coding:** [docs/agent-integration-guide.md](docs/agent-integration-guide.md), [docs/spatial-contract.md](docs/spatial-contract.md), [docs/host-contract.md](docs/host-contract.md), [docs/host-driver-contract.md](docs/host-driver-contract.md), [docs/gpu-context.md](docs/gpu-context.md), and [docs/embedding.md](docs/embedding.md).
2. **CMake, windowing, & `dlopen` packaging:** Apply `cmake/nvrhi-max-binding-layouts.patch` (`c_MaxBindingLayouts` 8 -> 16), supply Vulkan headers `>= 1.4.318` via `BEFORE PUBLIC`, configure NVRHI (`SHARED OFF`, `VULKAN ON`, `DX11/12 OFF`, `FETCH_VULKAN_HEADERS OFF`), install `glslangValidator` and build FidelityFX (`libamd_fidelityfx_vk.so` / `amd_fidelityfx_vk.dll`), enable C++20 + PIC (with IPO off around NVRHI/SDK), and for `dlopen` `.so` modules use hidden visibility + `--exclude-libs,ALL` + `$ORIGIN` + `dladdr()` asset lookup + bare `DT_NEEDED` FFX staging. Create a **non-GL/Vulkan window** (no GLX/WGL/`SDL_WINDOW_OPENGL`), force `SDL_VIDEODRIVER=x11` under Wayland (SDK supports Win32 & Xlib only), isolate `<X11/Xlib.h>` in one TU with `#undef None Bool True False Status Success Always Convex Complex TileShape`, and fall back from `QR_PRESENT_MODE_IMMEDIATE` to `QR_PRESENT_MODE_VSYNC` (`maxFrameLatency = 1`) on `QR_FEATURE_UNAVAILABLE`. Preserve bundled `Assets/textures/` fallback and distribute game packs using the host's native archive extension (`.pk3` for id Tech 3, `.pkz`/`.pak`/`.kpf` for Q1/Q2).
3. **Reuse `EditorSceneRuntime` & respect frame/teardown lifecycles:** Hook live VFS via `EditorAssetSource::SetVfsCallbacks`, set `includeInlineSubmodels = false` in runtime (upload moving `*1..*N` submodels per frame in world space as `QR_GEOMETRY_TYPE_DYNAMIC` with per-vertex nudged clusters, or `STATIC_MOVABLE` when valid), and call `CreateTextureMaterials()` **without** redundant `CreateSkyboxMaterials()`/`CreateScrollingSkyMaterials()` calls (avoids leaking 6 skybox materials and 3× decode). Call `DestroyGpuResources` **before** `qrDestroyInstance` (or `ResetGpuHandlesOnly()` after), free map materials on unload (`TEXTURE_COUNT_MAX = 4096`), never copy `EditorFrameParams` (internal self-pointers dangle), upload directional sun at most once/frame, set `renderUiOnly = QR_TRUE` on menu frames, guard secondary `RenderScene` calls, and allocate host dynamic `uniqueID`s in `>= 0x4000000000000000ull`.
4. **Spatial boundary, mandatory frame params, & config hygiene:** Call `qrSetSpatialConvention` once before uploads (`40 u/m`, `kEditorUnitsPerMeter = 40.0f`; supply both `pFaces` and `pFaceVertices` to `qrUploadWorldLights` when `det < 0`); pass explicit AgX `pTonemappingParams` (`nullptr` clamps `tmWhitePoint` to **`1.05f`**!), explicit `pBloomParams` (`bloomIntensity = 0` + `postEffectParams.pBloom`; `nullptr` triggers legacy `64x` bloom), initialized `pTexturesParams` (zeroed struct kills normal maps & all 64 `lightStyleScales`; `samplerAnisotropy = 0` is 16x default, `1` is off), explicit `pIlluminationParams` (`cellWorldSize = 2.0f`), even swapchain/`customRenderSize.width`, full-map `rayLength`/`cameraFar`/`skyboxRadius`, non-zero `worldUpVector`, and `allowGeometryWithSkyFlag = QR_TRUE`. Load authored `config.cfg` before clearing RT cvar `modified` flags and apply engine cvars with `onlyModified = true` so archived `q3config.cfg` never stomps authored scenes.
5. **PVS clusters (`<= 8192`), 0-based RLE `visData`, & light budgets:** Cluster `0` is reserved for solid/outside on vertices (`QrVertex::cluster`), while unclustered lights use **`QR_CLUSTER_LIGHT_NO_CLUSTER` (`~0u`)** — **NOT `0`**. Shift `visOffsets` (`[0] = -1`, `c -> c + 1`) and `skyVis` by `+1`, but keep bits inside zero-run RLE `visData` **0-based** (`Source/ClusterLightLists.cpp` already adds `+1`; trailing `0xFF` padding is not needed). Fold leaf-indexed maps exceeding `Q2_MAX_CLUSTERS = 8192` into `<= 8191` spatial clusters. Nudge solid-leaf vertices/lights into adjacent valid clusters; filter `power <= 0` and `kLightMinColorSum` (`0.0001f`) identically across spherical + cluster uploads; scale dynamic cluster power by `1600x`; keep `SURF_SKY` portals tagged `QR_GEOMETRY_VISIBILITY_TYPE_SKY` even with `SURF_NODRAW`.
6. **Predefined lights, `is_light`, & Light Editor parity:** Set `scene.usesExternalLightingModel = true` when the host supplies its lighting model, emit **all** predefined map lights (`light` / `lightJunior` entities **and** bucketed/deduplicated `q3map_surfacelight` / `lights.rad` fixtures) into both `scene.lights` and `scene.bspLights`, populate `defaultEmissiveTexture` on single-stage surface lights, register every managed YAML key in `IsEmittedMaterialKey`, author `light_focus` in `0..90°` (half-angle), and never double-emit BSP point lights + DTAL on one lamp.
7. **Multi-stage shaders, double-sided RT geometry, & Relief POM:** Split traced bases (`EditorSurface`) from overlays (`EditorOverlaySurface`), generate `isCutoutUnderlay` backings, duplicate `twoSided` (`cull none`) traced geometry with inverted normals/indices, guard file opens with `std::filesystem::is_regular_file`, bleed opaque neighbor RGB into alpha-0 index-255 cutouts, and satisfy Relief POM preconditions (normal bound + layer-2 albedo unbound + `parallax_scale` in `[0, 0.25]`, bypassed on glass/water/SSS/overlay-alpha).
8. **Cache invalidation & dynamic bake lifecycle:** **Never** call `sceneRuntime.dynamicMaterialBakes.BeginPass()/EndPass()` per frame in a runtime host (destroys cached dynamic materials on frame 2). On in-place editor texture edits, rebuild only that slot via `CreatePoolMaterial` and call targeted `InvalidateTexture(m_instance, existing)` on `m_materialBakes` / `m_previewMaterialBakes` *(note current SDK caveat: `InvalidateTexture` does not yet match `k.heightTex`)* — never global `Destroy(m_instance)` while static geometry is live.
9. **Runtime FX, decals, 2D `SWAPCHAIN`, & async readback (Guide §§1.4–1.6):** Route sprites, beams, translucent FX, additive shells, and surface decals via `qrUploadRasterizedGeometry` (point particles via `qrUploadParticles`, fixed `SRC_ALPHA / ONE_MINUS_SRC_ALPHA`) — never `qrUploadGeometry` (`ALPHA_TESTED` threshold is `(r+g+b)/3 * a + a < 0.5`). Keep `flags = 0` + smooth normals on dynamic models; drop fake engine blob shadows; clip decals with Sutherland–Hodgman prisms and upload them **before** explosions with raw darken textures (`ZERO / ONE_MINUS_SRC_COLOR`), `SRC_ALPHA / ONE` for energy marks, and `cameraNear = 1.0–3.0u`; set `TEXCOORD_TRANSFORM` (`256`) for `texCoordOffset`; use Vulkan Y-down NDC without depth flags on `SWAPCHAIN`; never mix `SMOKE` with `PARTICLE*` and populate non-zero `smokeLook`; map camera-left `+Y` to `u = 0`; and for `qrRequestFrameReadback`, always pump frames while polling and never free `readbackBuffer` before `qrDestroyInstance`.

## 3. Top Pitfalls to Avoid Immediately

See [docs/agent-integration-guide.md § Part 3](docs/agent-integration-guide.md#part-3--graveyard-of-pitfalls-what-broke-and-how-to-avoid-it) for the 1-screen triage table and full root causes / fixes (Pitfalls 1–32):

- **Pitfalls 1–2 (Architecture):** Never duplicate static pipelines between editor and runtime; never commit game-specific adapters inside `QuakeRaySDK/editor/`.
- **Pitfalls 3–4 (Lights & YAML):** Emit all `q3map_surfacelight`/`lights.rad` fixtures into `scene.lights` + `scene.bspLights`; never hardcode model filters; serialize empty lights as `lights: []`.
- **Pitfalls 5–6 (Shaders & POSIX I/O):** Separate traced base vs overlay, add `isCutoutUnderlay` backings, and check `std::filesystem::is_regular_file` before reading paths.
- **Pitfall 7 (GPU Material Caches):** Never call `dynamicMaterialBakes.BeginPass()/EndPass()` per frame in a runtime host (destroys cached handles on frame 2); use targeted `InvalidateTexture` (never global `Destroy`) on live scenes.
- **Pitfalls 8–9 (Models & CI Quality):** Normalize asset paths with `NormalizeEditorAssetPath`, validate MD3 indices `< numVerts`, subtract `animation.cfg` leg offsets, and satisfy `copyright_header.py`, `clang-tidy` (no `std::system()`), `cppcheck`, `lizard` (`CCN<=15/NLOC<=120/params<=7`), and `ruff`.
- **Pitfalls 10–12 (Patches, Rays, & Lighting Stability):** Tessellate `MST_PATCH` in 3×3 sub-patches with per-quad winding + seam normal welding; coordinate `rayLength`/`cameraFar`/`skyboxRadius`; default `giBounceRays = 1.0f` and `rt_restir 0` (1-frame uniform RIS flashes on dlights); match `kLightMinColorSum` filtering + `1600x` dynamic cluster power; avoid BSP + DTAL double emission.
- **Pitfalls 13–15 (FSR 3.1, Froxels, & Editor UX):** Keep `PrepareForSize` before `FillUniform`, capped `fHistoryWeight`, plane-distance `interpolate_lf`, and FFX `.so` rebuilds; keep tightened froxel grids + depth-bounds/zero-sigma early-outs; propagate `disabledStagesMask`/`mirror` and implement `buildPlayLevelCommand` + X11 `FocusIn` recovery.
- **Pitfalls 16–19 (Assets, AI Worker, HiDPI, & POM/Bump):** Rely on bundled `Assets/textures/`; run AI inference exclusively via out-of-process `quakeray_ai_worker` (`ggml-vulkan`, 75% VRAM, manual trigger, runtime `dlopen("libcurl.so.4")`, `PR_SET_PDEATHSIG`); scale widgets via `EditorGui*`; keep Relief POM bypassed on glass/water/SSS and check its normal-bound + layer-2-unbound preconditions.
- **Pitfall 20 (PVS & Multi-Engine Formats):** Keep RLE `visData` **0-based** (`visOffsets`/`skyVis` 1-shifted, no trailing `0xFF`), fold maps `<= 8191` clusters (`Q2_MAX_CLUSTERS = 8192`), use `QR_CLUSTER_LIGHT_NO_CLUSTER` (`~0u`), bleed opaque RGB into alpha-0 cutouts, and tag `SURF_SKY` portals `VISIBILITY_TYPE_SKY`.
- **Pitfalls 21–24 (Runtime FX, Decals, Sprites, & Smoke):** Keep sprites/FX/decals off `qrUploadGeometry`, smooth normals `flags = 0`, filter fake blob shadows, clip decals with Sutherland–Hodgman prisms before explosions, check `any(alpha < 250)`, never CPU-dim sRGB shells, never combine `SMOKE` + `PARTICLE*`, populate non-zero `smokeLook`, and map `+left` to `u = 0`.
- **Pitfalls 25–30 (Windowing, Frame Contracts, Readback, Double-Sided, Configs, Shaders, & Validation):** Use non-GL windows + `SDL_VIDEODRIVER=x11` + `VSYNC` fallback; pass explicit AgX tonemap/bloom/textures params and never copy `EditorFrameParams`; pump frames during `qrGetFrameReadbackStatus` and keep `readbackBuffer` alive past `qrDestroyInstance`; duplicate `twoSided` traced faces and register all YAML keys in `IsEmittedMaterialKey`; apply cvars with `onlyModified = true` and use Vulkan Y-down `SWAPCHAIN` + `TEXCOORD_TRANSFORM`; rebuild shaders strictly from `Source/Shaders/` using `getColumn(m, i)`, wrap storage images via `wrapEngineStorageImage`, and require `0` VUID errors under `VK_LAYER_KHRONOS_validation`.
- **Pitfalls 31–32 (GI Chroma Fidelity, Depth Metrology, & LF Anti-Ghosting):** Preserve `Q2_LF_CHROMA_TO_RADIANCE` (`1 / 0.282095`), `Q2_DIRECT_MAX_SPHERE_SOLID_ANGLE` (`2*pi` vs indirect `0.02`), bounded `emissionMaxScreenColor` (`4.0f` / `1.5f`), and `chromaPreservation` (`0.8f`); keep `q2DepthGradMode = 1u` (`Q2_DEPTH_GRAD_MIN_STEP = 0.0025` m), bounds-before-load + depth/normal-validated `deflicker_image` (`2.0`), and temporal antilag / grazing tangent-plane / 5×5 disocclusion moment invariants.

## 4. Mandatory Verification Commands (Before Every Push / PR)

```bash
# 0. Whenever HLSL shaders change (MUST run from inside Source/Shaders/, using Vulkan SDK dxc!)
(cd Source/Shaders && python3 -B CheckMatrixReads.py && python3 -B GenerateShaders.py -rebuild && python3 -B CheckShaderProperties.py)

# 1. Fast end-to-end check (CAVEAT: does NOT pass -DQR_BUILD_EDITOR=ON!)
bash tools/check_local.sh --asan --shaders

# 2. Full manual build WITH editor + isolated ggml-vulkan AI worker + compile_commands.json
cmake -S . -B build/local-quality -G Ninja -DCMAKE_BUILD_TYPE=Debug \
    -DCMAKE_EXPORT_COMPILE_COMMANDS=ON -DQR_BUILD_TESTS=ON -DQR_BUILD_EDITOR=ON \
    -DQR_NVRHI_SOURCE_DIR=/path/to/nvrhi -DQR_GGML_SOURCE_DIR=/path/to/ggml \
    -DQR_FFX_VK_SO=/path/to/libamd_fidelityfx_vk.so
cmake --build build/local-quality --parallel

# 3. CPU/policy tests (-LE gpu mandatory under Clang ASan/LSan) and standalone GPU suites
ctest --test-dir build/local-quality --output-on-failure -LE gpu
VK_LOADER_LAYERS_DISABLE=~implicit~ ctest --test-dir build/local-quality --output-on-failure -L gpu

# 4. Strict headers and diff-gated static analysis (ensure Vulkan SDK dxc is on PATH!)
which dxc && python3 -B tools/copyright_header.py --check --base origin/main
python3 -B tools/check_quality.py --strict-tools --shaders --base origin/main \
    --compile-commands build/local-quality/compile_commands.json
```
